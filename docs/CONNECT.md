# 平板与大屏连接步骤

## 0. 先确认拓扑

你的实际连接方式是：

```
安卓平板 ──Wi-Fi──▶ Windows 笔记本（跑 Node 服务）
                         │
                         ├── 主屏：主持页 /host
                         └── HDMI 扩展屏：大屏 /display
```

**大屏和主持页都在运行服务的这台笔记本上，用 `127.0.0.1` 打开，不经过局域网。只有平板必须走局域网 IP。**

这样安排的好处：大屏链路不受 Wi-Fi 波动和 Windows 防火墙影响，且不会出现"平板上的 localhost 指向自己"的误判。

## 1. 大屏（笔记本的 HDMI 扩展屏）

1. 确认 HDMI 线已接好，Windows 识别到第二块屏幕。
2. 按 `Win + P` → 选择**「扩展这些显示器」**（不要选"复制"或"仅第二屏"）。
3. 建议把扩展屏设为主显示尺寸一致的模式：设置 → 系统 → 屏幕 → 高级显示设置，确认分辨率 1920×1080、刷新率 60Hz。
4. 在笔记本上打开 Edge 或 Chrome，地址栏输入：

   ```
   http://127.0.0.1:3000/display
   ```

5. 把这个浏览器窗口移到 HDMI 屏：把鼠标移到窗口标题栏，按 `Win + Shift + →`（多按一次可跨更多屏幕）；或直接拖动过去。
6. 按 `F11` 进入全屏。
7. 右上角应显示路线徽章（`路线① 本机 TFJS` / `路线② ONNX CPU` / `路线③ 平板推理`），底部显示 `已连接服务`、`平板 N 台` 和比分。

> 如果 `Win + Shift + →` 不生效，直接用鼠标拖窗口到 HDMI 屏再 `F11`。页面按百分比布局，1920×1080 下效果最佳，其他分辨率也能自适应。

### 可选：一键把大屏页丢到第二显示器

服务启动后，双击项目根目录的 `open-display.bat`，会自动在**非主显示器**上以全屏窗口打开 `/display`。找不到第二块屏时退回主屏。它不会启动服务，请先运行 `start.bat`。

### 大屏防打扰

- 设置 → 系统 → 电源 → 屏幕和睡眠：接通电源时"从不"关闭屏幕。
- 打开"专注助手/勿扰模式"，避免通知弹窗盖住画面。
- 浏览器地址栏会自动隐藏（F11 全屏），演示前刷新一次确认无缓存残留。

## 2. 安卓平板

1. 查笔记本的局域网 IP：在笔记本上执行 `ipconfig`，记下 IPv4 地址（例如 `192.168.1.23`）。
2. 平板连接**同一个 Wi-Fi**（建议 5GHz；若路由器开了 AP 隔离会连不上，需关闭）。
3. 平板打开 Chrome / Edge，输入：

   ```
   http://<笔记本IP>:3000/draw
   ```

   例如 `http://192.168.1.23:3000/draw`。**不要用 `127.0.0.1` 或 `localhost`。**
4. 顶部状态显示 `已连接 · 路线…` 即正常。
5. 主持页点「开始本轮」后，平板中央出现「请画：XX」和倒计时。

### 触摸与笔刷

- 页面已设置 `touch-action: none` 并拦截 `touchstart/touchmove`，单指/多指都不会滚动或缩放页面。
- 笔刷半径默认 5（以 160×160 内部画布计），属于粗笔刷；要更粗改 `config/config.json` 的 `tablet.brushRadius` 后重启服务。
- 每 400ms 把画布转成 PNG 上传，白底线条图通常只有几百字节。
- 断线后自动重连（0.5s → 5s 封顶），笔画保留在页面内存中，恢复后继续上传。

### 安卓 Chrome 小技巧

- 菜单 → 「添加到主屏幕」，下次一键打开。
- 若地址被误判为搜索，请完整输入 `http://` 前缀。
- 关闭省电模式，避免锁屏导致 WebSocket 被系统断开。

## 3. 主持端（笔记本主屏）

打开 `http://127.0.0.1:3000/host`。

- 下拉框可指定谜题（留空为随机）。
- 「开始本轮」→ 平板出现题目、大屏清空进入等待猜测状态。
- 「立即锁定结算」→ 用当前 Top-1 按规则直接结算。
- 「重置」→ 清空当前回合，不写比分。
- 面板实时显示实际路线、骗AI模式开关、两端连接数、帧丢弃统计与内存占用。
- **选手与发奖榜**：先添加所有选手名字，默认自动轮转（当前高亮者即本轮画师，结算后自动切下一位）；结算自动按人计分并排名。
- **规则投屏**：点「投屏游戏规则」让大屏全屏显示规则页，「切回对战画面」返回；也可直接在笔记本打开 `http://127.0.0.1:3000/rules` 投屏。
- **科普页**：点「打开科普页 ↗」在新标签打开 `/science`，可在演示时逐层讲解 AI 如何识别。

## 4. 备选：如果大屏换成了另一台机器

只有当大屏不是这台笔记本的 HDMI 屏，而是另一台电脑时，才需要：

1. 那台机器也连同一局域网。
2. 把 `127.0.0.1` 换成 `http://<笔记本IP>:3000/display`。
3. 确认笔记本防火墙已放行 Node.js 的**专用网络**访问。

## 5. 快速自检

在笔记本上打开 `http://127.0.0.1:3000/api/status`：

- 有 JSON 输出 → 服务正常
- `route` 字段 → 实际推理路线
- `clients.draw` 应为 1（平板已连），`clients.display` 应为 1（大屏已连）

若平板端 HTTP 能打开但顶部一直显示"已断连"，检查防火墙与 IP；本项目不经过代理，直连 3000 端口。

## 6. 断连表现对照

| 现象 | 页面表现 | 处理 |
| --- | --- | --- |
| 平板 Wi-Fi 断开 | 平板显示"已断连 · Ns 后重连"；大屏底部显示"平板断连，等待自动重连…" | 恢复网络，自动重连 |
| 笔记本服务重启 | 两端都显示全屏"与服务断开连接"并重连 | 等待服务起来，自动恢复 |
| 大屏浏览器崩溃 | 平板不受影响；主持页显示大屏连接数 0 | 重新打开 `/display` 并 F11 |
| 模型加载失败（路线③） | 平板显示录屏 + 人工裁判提示；大屏徽章显示"路线③ 平板推理" | 换模型或转人工裁判 |
